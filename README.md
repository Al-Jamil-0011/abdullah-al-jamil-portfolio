# Portfolio

Personal portfolio website with a separate Admin Dashboard for full CMS management.

## Tech Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (auth, database, storage, edge functions)
- React Query
- React Router

## Local Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deployment

Deployed via Vercel. Any push to `main` triggers an automatic deployment.
